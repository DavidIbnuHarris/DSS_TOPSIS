# SPK TOPSIS (Sistem Pendukung Keputusan - Metode TOPSIS)

Aplikasi Sistem Pendukung Keputusan (SPK) menggunakan metode **TOPSIS** yang dibangun dengan **Laravel 10** (Frontend & Backend Manajemen) dan terintegrasi dengan **FastAPI (Python)** sebagai *engine* perhitungan matematisnya.

---

## 🛠️ Persyaratan Sistem
Sebelum menjalankan aplikasi ini di komputer lokal, pastikan Anda telah menginstal:
* PHP (Versi 8.2 atau lebih disarankan)
* Composer
* Python (Versi 3.8+) beserta pustaka FastAPI & Uvicorn
* MySQL / MariaDB (XAMPP atau Laragon)
